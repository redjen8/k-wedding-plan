# 결혼 준비 진행 구조 (일정·지출 체크용)

> 2026년 웨딩 플래너 안내 자료, 웨딩 컨설팅사 체크리스트(시기별 할 일, 웨딩홀 투어 질문, 인쇄물 2장)를 바탕으로 정리했다. 업체명, 추천인, 제휴 혜택, 개인 정보는 뺐다. 가격과 시점은 업계 관행이라 공식 통계(`wedding-cost-benchmarks-2026.md`)보다 출처 등급이 낮다. 일정 스킬(`wedding-schedule`)의 할 일 목록과 자금 스킬의 팁에 쓴다.

## 0. 시기별 할 일 (1년 6개월 전부터 거꾸로)

| 시기 | 할 일 |
|---|---|
| 1년 6개월 전 | 양가 첫인사(선물), 예식 형태·지역·시기, 우선순위(예산·위치·식사·주차·분위기), 예산 상한과 분담 방식, 결혼 준비용 통장·카드 |
| 1년 5개월 전 | 플래너(동행/비동행), 스튜디오·드레스·메이크업 계약, 웨딩홀 워크인 둘러보기 → 투어 → 계약, 스드메에 예식일 전달 |
| 1년 4개월~1년 전 | 본식스냅(홀 결정 직후), 본식영상, 아이폰스냅, 사회자, 헤어변형 예약, 상견례 장소·인원, 관리(제모·피부·체중) 시작 |
| 1년~8개월 전 | 신혼여행지, 항공권(최소 6개월 전), 숙소, 웨딩밴드, 신혼집·혼수 논의, 신랑 예복(촬영 2~3개월 전 방문) |
| 7개월 전 전후 (촬영 기준) | 드레스 투어(촬영 1달 전), 이미지 상담, 촬영 시안·소품·의상, 웨딩 네일(촬영 1주~하루 전), 촬영 |
| 6개월 전 | 가전·가구, 혼주 한복(예약 후 예식 1~2개월 전 선택), 혼주 정장, 혼주 메이크업, 원본 셀렉(촬영 2주 후, 추가금 주의) |
| 5~3개월 전 | 청첩장 인쇄 부수·문구, 청첩장 모임(예식 1달 전까지 끝내기, 1인 3만~5만원), 식순, 식전영상, 축의대·축가·축사 섭외 |
| 3~1개월 전 | 모바일 청첩장, 본식가봉, 웨딩홀 시식(기본 2인), 꽃장식 요청, 부케(1달~2주 전 필수), 보증인원 최종 확정(오는 사람 1, 애매 0.5, 안 옴 0으로 계산), 무리한 시술 금지 |
| 1주 전 | 평일 리허설, 현금 봉투(헬퍼비·사례비), 염색·커트, 환전·짐 |
| 하루 전 | 예복·혼주 한복 픽업과 상태 확인, 식순 숙지, 짐 |
| 예식 후 | 본식영상 수령(약 3개월 후), 스냅·스튜디오 앨범(셀렉 후 3~4개월) |

보충(업계 통상, 공식 기준 없음):
- 웨딩밴드는 주문 후 수일~2주(각인하면 더 걸림), 맞춤 예복은 4~6주
- 청첩장은 예식 2개월 전 제작
- 예복(신랑, 양가 아버지, 남자 형제)과 한복(양가 어머니, 폐백을 하면 신랑신부)은 촬영이나 예식 3개월 전 준비
- 보증인원 변경 마감은 홀마다 달라서 계약서에서 확인해야 한다

추가금 구조:
- 대관비 = 홀 사용료 + 혼구용품 + 폐백실 사용료 + 폐백 의상
- 폐백 수모비 별도. 2부 진행은 서비스인 홀도 있고 추가비용인 홀도 있다
- 스튜디오 기본은 20P 앨범 + 20R 액자. 원본·수정본은 포함되기도 하고 필수 구매이기도 하다. 한옥·야간·야외 배경과 촬영 시간·벌수 초과는 추가금
- 드레스 헬퍼비는 야간, 장시간 촬영, 야외, 2부, 수모 대행, 지역 출장 때 더 붙을 수 있다. 재피팅과 애프터 드레스도 추가
- 메이크업은 시작 시간 추가금, 커트·염색·펌, 헤어피스, 네일, 휴무일 차지, 담당자 지정비(현장 결제)가 붙는다. 유명 샵은 담당자가 바뀔 수 있다
- 본식스냅은 메인 작가 1인 + 합본·혼주 앨범이 흔한 기본이고, 작가 추가, 수정, 셀렉, 지정, 출장, 추가 장소 촬영은 별도. 본식영상은 1인 1캠 50만원부터
- 부케 세트(부케, 부토니에, 코사지)는 배송비, 코사지 추가, 평일 배송 추가금이 있을 수 있다
- 연주(3중주·4중창)와 축가는 지역 출장비가 붙을 수 있다

## 0-1. 웨딩홀 투어 때 확인할 것

- 하객 편의: 대중교통, 셔틀버스와 간격, 주차 대수·연계 주차장·무료 시간, 엘리베이터, ATM
- 홀: 단독홀 여부, 대관료와 포함 항목, 꽃장식 종류·추가금, 플라워샤워, 예식 간격, 보증인원, 좌석 수, 분위기(밝기·천고·버진로드), 조명·음향
- 로비: 크기, 축의대 위치, 포토테이블, 화환 반입
- 신부대기실: 홀과 연결, 분위기, 전용 화장실
- 연회장: 홀과 동선, 식대(성인·아동), 주류·음료 포함, 식사 형태·시간, 식권, 혼잡도, 스크린, 당일 추가 가능 인원과 단가
- 혼주: 연계 메이크업샵, 외부 메이크업 가능 여부, 메이크업·탈의 공간, 락커
- 계약 조건: 계약금 무료 취소 기간, 현금영수증, 부가세 포함 여부, 시식 인원, 당일 계약 혜택

## 1. 정하는 순서

1. 웨딩홀
2. 스튜디오
3. 드레스 투어 → 드레스샵 결정, 헤어변형 예약
4. 메이크업샵
5. 예복·예물·한복
6. 청첩장, 본식스냅·영상

플래너 제휴 업체가 아닌 곳을 따로 예약하면 제휴 할인을 못 받을 수 있다. 개별 예약 전에 플래너에게 먼저 묻는다.

## 2. 스드메 세부 일정

| 단계 | 하는 일 | 시점·소요 | 비용·주의 |
|---|---|---|---|
| 드레스 투어 | 샵마다 1시간, 4벌 피팅, 마음에 드는 2벌 찜 | 촬영 전. 샵 2~4곳 | 샵당 투어비 5만~6만원. 투어 2주 전쯤부터 취소하면 위약금 |
| (대안) 지정 촬영가봉 | 투어 없이 샵 한 곳을 골라 바로 촬영가봉 | 일정이 촉박하거나 할인을 원할 때 | 투어비 절약 |
| 메이크업샵 결정 | 신부 이미지에 맞춰 선택 | 상담 1회 | 펌·염색·네일·붙임머리는 별도. 직급·담당자 지정은 별도. 이른 아침 시작이면 얼리스타트비 5만~15만원 |
| 촬영가봉 | 촬영용 드레스 고르기와 사이즈 조정. 5~6벌 피팅 후 3벌 | 촬영 1~3주 전 예약, 1시간 | 가봉 1달 전쯤부터 취소·변경하면 위약금 |
| 스튜디오 촬영 | 웨딩 사진 촬영 | 4시간 안팎 | 촬영 4~6개월 전부터 취소·변경 위약금. 야간 촬영·지역 출장비 별도 |
| 사진 셀렉 | 앨범·액자 사진 고르기, 원본 수령 | 촬영 후, 2~3시간 | 앨범 페이지 추가, 액자 업그레이드 추가금 |
| 본식가봉 | 본식 드레스 고르기. 4벌 피팅 후 1벌 | 예식 3주~1달 전 예약 | 2부 드레스도 이때 함께 고름 |
| 예식 당일 | 메이크업, 드레스 헬퍼 동행 | — | 헬퍼비 회당 25만~30만원(촬영·본식 각각), 현금 지급이 많음 |

## 3. 결제 패턴

- 웨딩홀: 계약할 때 계약금(총액의 10% 안팎, 홀마다 다름). 나머지는 예식 당일 정산하고, 축의금으로 내는 경우가 많다. 계약금은 당일 정산액에서 뺀다.
- 스드메: 계약금은 총액의 10%. 중도금은 촬영 1달 전, 잔금은 예식 1달 전.
- 현장 추가금(헬퍼비, 얼리스타트비, 출장비): 해당 일정 당일.

| 항목 | 범위 |
|---|---|
| 스드메 패키지 | 실속 300만~400만 / 보통 500만~600만 / 고가 700만~2,000만원. 기본가가 싼 업체일수록 추가금이 많이 붙는 경향 |
| 드레스 헬퍼 | 촬영·본식 각 25만~30만원 |
| 드레스 투어비 | 샵당 5만 5천원 안팎 |
| 신랑 예복 | 맞춤 170만~250만원(대여 몇 벌 포함), 대여 1벌 25만~40만원 |
| 커플링 | 종로 150만~250만 / 청담 250만~300만 / 명품 500만원 이상 |
| 혼주 한복(어머님 1인) | 맞춤 50만~140만 / 대여 35만~50만원. 아버님 정장은 별도 |
| 혼주 메이크업 | 여혼주 1인 15만~30만, 남혼주 1인 5만~10만원 |
| 종이 청첩장 | 13만원부터 |
| 본식스냅 | 30만~200만원대. 너무 싼 곳은 경험이 적은 작가가 올 수 있음 |
| 본식 영상 | 40만~200만원대 |

## 5. 플래너 패키지에 흔히 들어가는 서비스

- 생화 부케 세트(부케, 부토니에, 코사지). 계절·꽃 수급에 따라 추가금이 생길 수 있다
- 스드메 일정 동행(드레스 투어, 촬영가봉, 촬영, 본식가봉, 예식 당일)
- 제휴 업체 할인(허니문, 예복, 예물, 한복, 가전·가구, 청첩장)

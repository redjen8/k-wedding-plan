# 결혼 준비 일정 (wedding-schedule)

대화로 정보를 모아 `input.json`을 쓰고, `scripts/build_schedule.py`로 수식이 살아 있는 엑셀을 만든다. 엑셀은 직접 조립하지 않는다.

범위는 **예식 준비 일정**이다. 신혼집·혼수·관리(제모·피부·체중)는 선택 항목으로 들어 있다. 신혼집 계약, 대출, 혼인신고, 세금은 다루지 않는다. 질문이 나오면 범위 밖이라고 말한다. 비용은 `wedding-budget` 스킬을 안내한다.

## 1. 정보 모으기

한 번에 하나씩 묻는다.

1. 신랑·신부 이름(호칭). 밝히기 싫다고 하면 "신랑", "신부"로 둔다.
2. 예식일 (YYYY-MM-DD). 미정이면 목표 월을 묻고 그 달 15일로 넣은 뒤 `wedding_date_estimated: true`로 둔다.
3. 스튜디오 촬영일. 미정이면 비워 둔다. 엑셀이 예식 150일 전으로 추정하고, 날짜가 정해지면 기본정보 시트의 셀 하나만 고치면 된다고 알려준다.
4. 이미 끝낸 일. 아래 id 목록에서 고르게 돕는다(예: 웨딩홀 계약, 스드메 계약, 상견례). → `done`
5. 신혼집 준비(입주 시점, 가전·가구, 이사, 인터넷)도 일정에 넣을지 따로 묻는다. 넣지 않으면 `skip`에 `"신혼집"`을 넣는다.
6. 하지 않을 것. 아래 태그 중에서 묻는다(폐백, 2부, 플래너, 아이폰스냅, 상견례선물, 식전영상, 관리, 예식후). → `skip`
7. 투어할 웨딩홀이 있으면 이름(최대 4곳). → `halls`

`skip`한 할 일은 지우지 않고 상태를 "해당없음"으로 두며 진행률 계산에서 빠진다. 나중에 하게 되면 상태만 "예정"으로 바꾸면 된다고 알려준다.

## 2. input.json

```json
{
  "groom": "김신랑", "bride": "이신부",
  "wedding_date": "2027-04-17",
  "wedding_date_estimated": false,
  "shoot_date": "2026-12-05",
  "skip": ["폐백", "아이폰스냅"],
  "done": ["first_greeting", "hall_contract", "sdm_contract"],
  "halls": ["A웨딩홀", "B컨벤션"]
}
```

- 필수 값은 `wedding_date` 하나다.
- `skip`에는 태그나 할 일 id를 넣는다. 해당 할 일이 "해당없음"으로 시작한다.
- `done`에는 할 일 id를 넣는다. 해당 할 일이 "완료"로 시작한다.
- 할 일 전체(id, 단계, 시점, 팁)는 `references/checklists.json`에 있다. 자주 쓰는 id:
  - 기초: `first_greeting`(첫인사), `wedding_style`(예식 형태·시기), `priorities`(우선순위), `budget_agree`(예산 합의)
  - 예식장: `hall_walkin`, `hall_tour`, `hall_contract`, `planner`, `sdm_contract`, `sdm_date`
  - 본식 업체: `snap_book`(본식스냅), `video_book`(본식영상), `mc_book`(사회자)
  - 그 외: `sanggyeonrye`(상견례), `flight`(항공권), `ring`(웨딩밴드), `groom_suit`(신랑 예복), `dress_tour`(드레스 투어), `shoot_day`(촬영)
- 전체 예시는 `examples/sample_input.json`에 있다.

## 3. 엑셀 만들기

```bash
python3 scripts/build_schedule.py --input input.json --out 결혼준비일정.xlsx
```

`openpyxl`이 없으면 `pip install openpyxl`을 먼저 실행한다. `입력 오류:`가 나오면 메시지대로 JSON을 고쳐서 다시 실행한다.

시트 구성:
- **개요**: D-day, 진행률, 지연·마감 임박·지금 할 때 개수, 단계별 진행
- **기본정보**: 예식일·촬영일(확정/추정), 마감 임박 기준(기본 14일)
- **타임라인**: 할 일마다 기준(예식일/촬영일), 시작·마감 D-, 날짜, 상태, 남은 일수, 알림. 필터가 걸려 있다
- **웨딩홀투어**: 확인할 질문 42개 × 홀 4곳. 우선순위 가중치 × 점수로 가중 총점과 1위를 계산
- **당일체크**: 준비물, 역할 담당, 현금 봉투(합계 자동)

노란 칸이 입력 칸이다. 미리보기에서는 수식 칸이 비어 보이고, Excel·Numbers·Google 스프레드시트로 열면 계산된다고 안내한다.

## 4. 결과 해설

엑셀을 건넨 뒤 대화로 짧게 정리한다. 날짜는 직접 계산해서 말한다(시작일 = 기준일 - 시작 D-, 마감일 = 기준일 - 마감 D-).

1. 지금 지연된 할 일과 2주 안에 마감되는 할 일
2. 이번 달과 다음 달에 시작할 일
3. 늦게 시작해서 지연이 많으면 압축 순서를 제안한다. 웨딩홀 → 스드메 → 본식스냅 → 촬영일 확정 → 예복·드레스 순서처럼 앞 일정이 뒤 일정을 막는 것부터 처리하게 한다.
4. ★ 표시(놓치기 쉬운 일)인데 사용자가 언급하지 않은 것. 예: 계약서에서 보증인원 변경 마감 확인, 부케 예약, 현금 봉투
5. 시점은 업계 관행이고 업체·계약마다 다르니 **계약서 날짜가 우선**이라고 고지한다. D- 일수는 엑셀에서 직접 고칠 수 있다.

하지 말 것:
- 계약서에서 확인해야 할 날짜(취소 위약금 기한, 보증인원 마감)를 단정하지 않는다.
- 사용자에게 받은 이름과 날짜를 다른 사람의 예시로 쓰지 않는다.
